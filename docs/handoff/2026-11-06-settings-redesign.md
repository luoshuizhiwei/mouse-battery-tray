# 设置窗口视觉优化

日期：2026-11-06，Asia/Hong_Kong。用户授权优化当前页面；本轮仅重做设置窗口的视觉与控件呈现，没有修改任务栏胶囊、HID读取、快照ABI或原生DLL。

## 设计与实际改动

基于真实设置窗口观察：原数字与百分号分离、辅助文字过小、位置示意难理解、重复PRO X徽标和蓝/紫强调色混用。

- 继续沿用明暗Catppuccin基色，以蓝色为本窗口唯一正常状态强调色；电量低于阈值仍保留黄/红警示语义。
- 字体：Segoe UI Variable Display用于读数，Microsoft YaHei UI用于中文设置，Segoe UI用于设备型号。放大数值与状态文字，去掉重复型号徽标。
- `BatteryReadout`使用同一绘制坐标系排版数字和小百分号，避免两个Label测量方式不同导致大空隙；没有读数时只显示`--`。
- 电量的可访问性名称同步实际值，例如80%或暂无电量，屏幕阅读器无需从通用控件名猜测数值。
- 20段电量刻度，每段5%，末段按实际值填充；蓝色刻度与位置选中状态、启动开关、完成按钮统一。
- 位置选择改为4个文字选项：任务栏左端、托盘左侧、时钟左侧、时钟右侧。保留原始位置编码和左右键次序；焦点提示和鼠标点击目标明确。
- 分开位置标题、当前完整位置、选择控件与即时生效说明。保留完成/退出的功能与Enter/Esc行为。
- 普通窗口客户区560×608，降级560×512；保留系统主题跟随；高度超出当前工作区时限制窗口并启用滚动。
- 降级提示使用可读警示色和用户语言，不再在页面挤入长哈希。

产品改动文件仅`src/Program.cs`与`src/Ui.cs`。原文件与正式版保存在`E:\MouseBattery\ui-refine-20261106\before`。旧交接入口保存在`2026-11-06-before-settings-redesign.md`；没有提交/push。
