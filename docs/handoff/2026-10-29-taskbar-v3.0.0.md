## 实现

`NativeHost.cs` 验证系统 taskbar.dll 完整 SHA256、展开内嵌 DLL、检查同会话健康状态并连接 Explorer。`NativeHost.cpp` 使用 Windows API 加载本项目 DLL，在任务栏 UI 线程调度原生布局，监视读取进程句柄和停止事件；正常退出或读取进程死亡后移除布局、平衡模块引用并卸载。`TaskbarView.h` 保留 v2.1 的视图与布局逻辑，移除了 Windhawk API。

新增组件仅依赖 Windows 系统 DLL。Clang 工具链仍复用历史构建目录 `<部署目录>\taskbar-v2\build-tools\Compiler`，属于构建依赖，不是运行依赖。Framework C# 编译器路径保持原样，无 .NET SDK/NuGet 安装。

本轮修复退出时重复 Dispose 的实际故障。另定位到用户缓存路径对 Explorer 不可见：同一 DLL 完整指纹相同，Explorer 查询缓存路径返回路径不存在，而 E 盘应用目录能加载；改为应用目录展开。原始失败探针保留于证据目录，没有修改系统权限或安全设置。健康状态 UTF16 字符串改为读取首个 NUL，避免较短状态尾部残留旧字符。
