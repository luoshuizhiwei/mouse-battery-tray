## 实现

`src/Hid.cs`、`src/Battery.cs` 的设备逻辑复用旧版。读取进程以 512 字节的版本化共享内存发布状态，使用奇偶提交序列与单调时钟时间戳。原生模块不调用 HID；过期 15 秒强制隐藏。读取程序正常退出时主动发布隐藏。

任务栏模块在 Explorer 的任务栏 UI 线程构造 XAML Border/TextBlock。新版 SystemTrayFrameGrid 实测是 StackPanel，直接插入独立项目；最左端 RootGrid 使用独立列，保留并还原原有隐式列。卸载/隐藏会移除控件和占位。未使用通知图标或顶部悬浮窗模拟任务栏文本。

四个预设位置：0 系统托盘/时钟区域左侧（默认）；1 紧邻时钟左侧；2 时钟右侧；3 任务栏左端。位置 3 会避开当前左端已有的 TrafficMonitor 子窗：其范围 x=1..254 DIP，本工具实测 x=262..318 DIP。

右键菜单提供设置、自启开关和退出读取程序。管理窗口提供位置选择、自启开关、关闭窗口和退出工具。自启开关同时管理本工具读取程序与宿主的两个 Run 值，保留其他应用和 Windhawk 的其他配置。

## 实际修复与失败保留

- 首次 native 构建缺 WinRT 集合头、GetCurrentTime 宏冲突和 oleaut32 链接；原始失败 `mod-build.txt` / `mod-build-fixed.txt` 保留，最终正常构建。
- 左端原型宽度错误地达到 617 DIP；根因为默认隐式列被插入后的唯一列替代，原生子元素被夹到同一列。显式保留原隐式星号列后恢复 56 DIP，测试结束恢复默认列结构。红/绿记录 `native-positions-first.txt` / `native-positions-grid-fixed.txt`。
- TrafficMonitor 虽被枚举为任务栏后代，但 GetParent 返回弹出窗 owner，直接父级过滤漏检；移除该错误过滤后左端正确避让到 x=262。保留 `window-tree-current.txt` 与最终布局记录。
- 一次替换读取程序时，5 秒退出等待上限先到，脚本及时停止覆盖；随后确认进程已退出再替换，最终仅一个读取实例。无崩溃证据，未放宽读取或过期语义。
