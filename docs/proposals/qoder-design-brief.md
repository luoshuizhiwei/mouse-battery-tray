## 产品是什么

常驻任务栏的小胶囊显示鼠标电量百分比，悬停出仪表卡（设备名、大数字、充电状态、刻度条），右键出菜单，另有 WinForms 设置窗口和降级托盘图标。它是"系统原生部件"而非"应用窗口"——设计目标是让它像 Windows 官方出的组件，同时有可辨识的个性。

## 铁律（设计不得违反）

1. 任务栏胶囊只显示百分比数字，不加图标/文字
2. 胶囊左键零动作（防误触）
3. 胶囊静息纯文字无底色（与原生时钟同构），悬停才显玻璃底
4. 无位移动画——"流畅"= hover/pressed 反馈即时干净
5. 双鼠差异化用产品线视觉语言：PRO X=Mauve、M750L=Sapphire，不出现"电竞/办公"分类词
6. 托管 C# 为 C# 5 语法上限（影响可实现的效果范围，设计时注意）
7. 快照 ABI（512B）不可改

## 设计任务（五部分，写入 docs/proposals/catppuccin-design.md）

### 1. 悬停仪表卡（重点）
现状是"信息堆叠的表单"。重新设计信息层级：设备名+产品线色点、大数字与 % 的排版关系、充电状态行、刻度条与两侧阈值刻度、伴随设备行（第二只鼠标摘要）。给出精确到 DIP 的版式规格（行高、间距、字阶、对齐）、每个元素的颜色 token 引用、形状语言（圆角/描边/分隔线/材质）。电竞卡与办公卡的差异体现在材质（描边/色点），不靠文字。

### 2. 设置窗口（重点）
现状是"初稿"。给出完整版式重构：信息架构（信息优先级排序）、卡片层次（Surface/Border 做深度）、迷你任务栏位置选择器精修（落点/hover/选中三态）、ToggleSwitch 完整状态机（rest/hover/pressed/disabled/焦点）、按钮体系（主/次按钮三态）、标题区与产品线 chip。精确到 DIP，标注每个元素取哪个 token。

### 3. 任务栏胶囊
静息态铁律限制下，设计空间：字阶（15px 基准可±1）、百分号比例与透明度、悬停玻璃底材质（渐变方向/强度/描边组合）、阈值变色时玻璃底联动。给参数表。

### 4. 降级托盘图标
电池壳精修：线宽比例、圆角、nub 形状、数字与壳比例。给参数表。

### 5. 设计系统附录
所有决定收敛为 token 总表（颜色/几何/字阶/间距/状态色），标注与现有 `src/Ui.cs` 的差异，供实现轮直接替换。
